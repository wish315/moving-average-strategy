# 沪深300多策略趋势跟踪滚动回测系统

基于 **沪深300指数** 的量化回测项目，实现 4 种经典趋势跟踪策略，采用 **5年训练 + 2年样本外验证** 的滚动窗口寻参框架，并统一叠加 **MA250 年线趋势过滤** 与交易成本（手续费万3双边 + 滑点万2单边），评估策略的真实样本外表现。

> ⚠️ **风险提示**：本项目仅用于量化研究与教学演示，历史回测表现不代表未来收益，不构成任何投资建议。

---

## ✨ 项目亮点

- **4种策略横向对比**：均线交叉（MA）、MACD、动量（Momentum）、唐奇安通道突破（Donchian）
- **滚动窗口寻参**：每期用过去5年数据网格搜索最优参数，在随后2年样本外验证，避免"用未来数据"的过拟合陷阱
- **趋势过滤**：买入信号仅在收盘价站上250日年线时生效，规避熊市中的虚假突破
- **真实交易成本**：每笔交易计入手续费（万3）与滑点（万2），绩效更贴近实盘
- **完整绩效指标**：年化收益、夏普比率、最大回撤、交易次数，并与"买入持有"基准逐一对比
- **参数敏感性可视化**：双参数策略输出夏普比率热力图，直观展示参数平原

## 📊 回测指标说明

| 指标 | 计算方式 |
|------|----------|
| 年化收益 | (1 + 区间总收益)^(252/交易日数) - 1 |
| 夏普比率 | (年化收益 - 2%无风险利率) / 年化波动率 |
| 最大回撤 | 净值相对历史新高的最大跌幅 |

## 🚀 快速开始

### 1. 环境准备

```bash
# Python 3.9+ 推荐
pip install -r requirements.txt
```

### 2. 运行滚动回测

```bash
cd src
python backtest.py
```

运行后将依次输出：

1. 各滚动窗口内 4 种策略的最优参数与样本外绩效
2. 绩效汇总表 → `results/backtest_summary.csv`
3. 各策略净值曲线 + 回撤序列图
4. 各策略年度平均年化收益柱状图

### 3. 交互式分析

```bash
jupyter notebook notebooks/backtest_report.ipynb
```

## ⚙️ 可调参数（`src/backtest.py` 顶部）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `FEE_RATE` | 0.0003 | 手续费（双边万3） |
| `SLIPPAGE` | 0.0002 | 滑点（单边万2） |
| `ROLL_TRAIN_WINDOW` | 1260 | 滚动训练窗口（5年） |
| `ROLL_VALID_WINDOW` | 504 | 滚动验证窗口（2年样本外） |
| `START_SEARCH_DATE` | 2006-01-01 | 回测数据起始日期 |
| `PARAM_GRIDS` | 见代码 | 各策略参数网格，可自行扩展 |

## 📈 策略逻辑简介

| 策略 | 买入条件 | 卖出条件 |
|------|----------|----------|
| MA均线 | 短均线上穿长均线 且 价格 > MA250 | 短均线下穿长均线 |
| MACD | DIFF上穿DEA 且 价格 > MA250 | DIFF下穿DEA |
| 动量 | N日动量翻正 且 价格 > MA250 | N日动量翻负 |
| 唐奇安 | 收盘价突破前N日最高价 且 价格 > MA250 | 收盘价跌破前N日最低价 |
